# Task 02 — Database Search and Annotation

A reproducible nucleotide database search workflow using NCBI Nucleotide and remote BLASTN.

## Query sequence
- Gene: **ACTB** (beta-actin)
- Organism: *Homo sapiens*
- RefSeq accession: **NM_001101.5**
- Molecule: mRNA
- Source: [NCBI Nucleotide record](https://www.ncbi.nlm.nih.gov/nuccore/NM_001101.5)

This public reference was selected because no internship-provided sequence was supplied. Confirm accession metadata and current record length on NCBI before reporting it.

## Workflow
1. Download the accession in FASTA format using NCBI Entrez.
2. Run remote **BLASTN** against NCBI's `nt` nucleotide database.
3. Save the raw BLAST XML report.
4. Extract subject accession/title, alignment length, percent identity, approximate query coverage, E-value, and bit score.
5. Write a CSV annotation table.

## Search parameters
| Parameter | Value |
|---|---|
| Program | BLASTN |
| Database | `nt` |
| Search mode | MegaBLAST |
| E-value threshold | 10 |
| Maximum hits retained | 10 |
| Query | `NM_001101.5` |

NCBI may queue remote searches, so a run can take several minutes. Avoid submitting repeated requests rapidly.

From the repository root:

```bash

```

Optional arguments:

```bash
python blast_search.py --accession NM_001101.5 --database nt --hits 10
```

## Output
- `data/query_sequence.fasta` — downloaded query
- `results/blast_results.xml` — raw BLAST report
- `results/annotation_table.csv` — parsed hit table

The result files are generated by running the script. **No BLAST hit values are fabricated or pre-filled.**

## Interpretation
- **Percent identity:** identical aligned positions divided by alignment length.
- **Query coverage (approx.):** alignment length divided by query length, capped at 100%; this is a simple one-HSP approximation.
- **E-value:** expected number of chance matches with a score at least this good; smaller values indicate stronger statistical significance.
- **Bit score:** normalized alignment score; higher is stronger for comparable searches.
- **Subject accession/title:** identifies the matched database record. Inspect the NCBI record before assigning gene/function.

High identity and coverage with a very small E-value support sequence similarity, but similarity alone does not prove biological function.

Paste `NM_001101.5` into [NCBI BLASTN](https://blast.ncbi.nlm.nih.gov/Blast.cgi) and select the nucleotide collection (`nt`) database.
